# D4 — API de referência publicada

Publicação de referência do **laboratório 06** (D4, UTFPR/CEAI): a API de
exemplo do pacote de abertura (domínio de oficina) no ar, com as rotas de
saúde (`/health`) e de decisão de exemplo (`/decidir`). **Sem dado de
domínio** — é a regra do roteiro do laboratório.

A configuração (banco gerenciado do ramo de publicação) entra pelas variáveis
de ambiente do serviço, por fora da imagem — é o que o slide 20 do D4-E4
ensina.
